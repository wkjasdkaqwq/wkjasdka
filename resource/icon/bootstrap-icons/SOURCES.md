# Bootstrap Icons

Client and Server icons are loaded from the Bootstrap Icons 1.13.2 CDN distribution. The original Release Date and Last Updated SVG paths are inlined in `community.html` so that a uniform vector outline can be applied.

- Client — `display.svg`: <https://github.com/twbs/icons/blob/main/icons/display.svg>
- Server — `hdd-stack-fill.svg`: <https://github.com/twbs/icons/blob/main/icons/hdd-stack-fill.svg>
- Official site — `globe.svg` (path inlined in `community.html` to apply the Detail icon outline): <https://github.com/twbs/icons/blob/main/icons/globe.svg>
- GitHub profile — `github.svg` (path inlined in `community.html` to apply the Detail icon outline): <https://github.com/twbs/icons/blob/main/icons/github.svg>
- Open Official site action — `box-arrow-up-right.svg` (loaded from the Bootstrap Icons 1.13.2 CDN): <https://github.com/twbs/icons/blob/main/icons/box-arrow-up-right.svg>
- Release Date — `file-earmark-arrow-up.svg`: <https://github.com/twbs/icons/blob/main/icons/file-earmark-arrow-up.svg>
- Last Updated — `pencil-square.svg`: <https://github.com/twbs/icons/blob/main/icons/pencil-square.svg>
- Gallery edge cursors — `arrow-left.svg` and `arrow-right.svg` (Bootstrap Icons 1.13.2; fill and stroke changed to white for contrast on the preview backdrop, rendered at 48×48 with shaft stroke width increased 20% from 0.05 to 0.06 viewBox units): <https://github.com/twbs/icons/blob/v1.13.2/icons/arrow-left.svg>, <https://github.com/twbs/icons/blob/v1.13.2/icons/arrow-right.svg>
- CDN base: <https://cdn.jsdelivr.net/npm/bootstrap-icons@1.13.2/icons/>

The upstream license is retained as `LICENSE.txt`.
