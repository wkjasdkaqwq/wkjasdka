# Mod-loader icon sources and attribution

All button icons are stored in this directory and referenced locally by `community.html`. The adjacent loader name remains the accessible button label.

| Loader | File | Source and notes |
|---|---|---|
| Fabric | `fabric.png` | 500×500 logo served by the official Fabric documentation site: <https://docs.fabricmc.net/logo.png>. |
| Forge | `forge.png` | 384×384 image from the official MinecraftForge GitHub organization avatar: <https://github.com/MinecraftForge>. It uses the official white anvil mark on its dark navy background for contrast in dark mode. |
| Legacy Fabric | `legacy-fabric.png` | Official Legacy Fabric site asset: <https://github.com/Legacy-Fabric/legacyfabric.net/blob/master/res/img/logo.png>. The upstream repository uses BSD 3-Clause; see `LICENSE-Legacy-Fabric.txt`. |
| LiteLoader | `liteloader.png` | User-provided 224×224 JPEG converted to PNG; the near-white background connected to the image edges was made transparent while preserving the Loader artwork. |
| NeoForge | `neoforge.png` | Converted from the official NeoForged 128×128 icon: <https://github.com/neoforged/.github/blob/main/art/neoforged.ico>. The art repository README identifies its art as CC BY 4.0; attribution: NeoForged team, “NeoForged icon,” source linked here, CC BY 4.0. |
| Quilt | `quilt.png` | Official Quilt transparent mini icon, 128 px PNG: <https://github.com/QuiltMC/art/blob/master/brand/128png/quilt_mini_icon_transparent.png>. Quilt’s art repository provides CC0 1.0 for copyright and related rights; trademark rights are not waived. |
| Rift | `rift.png` | 256×256 project icon from CurseForge’s Rift listing (project ID 297501): <https://www.curseforge.com/minecraft/mc-mods/rift>. Direct image: <https://media.forgecdn.net/avatars/thumbnails/160/214/256/256/636664101876595065.png>. The connected white page background was removed while retaining the cube icon and its transparent background. |
