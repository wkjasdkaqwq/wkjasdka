# Mod-loader icon sources and attribution

All button icons are stored in this directory and referenced locally by `community.html`. The adjacent loader name remains the accessible button label.

| NeoForge | `neoforge.png` | Converted from the official NeoForged 128×128 icon: <https://github.com/neoforged/.github/blob/main/art/neoforged.ico>. The art repository README identifies its art as CC BY 4.0; attribution: NeoForged team, “NeoForged icon,” source linked here, CC BY 4.0. |
